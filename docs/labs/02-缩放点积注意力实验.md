# 缩放点积注意力实验

## 实验目标

把缩放点积注意力拆成三个可见步骤：相似度打分、概率归一化、Value 加权求和。

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

```python exec lab="scaled-dot-product-attention" cell="1" title="Create query keys and values" difficulty="basic"
from math import exp, sqrt

query = [1.0, 0.0]
keys = [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
values = [[10.0, 0.0], [0.0, 10.0], [6.0, 6.0]]

assert len(query) == len(keys[0])
assert len(keys) == len(values)
print({"query_shape": (1, len(query)), "key_shape": (len(keys), len(keys[0]))})
```

```python exec lab="scaled-dot-product-attention" cell="2" title="Compute attention weights" difficulty="basic"
def dot(left, right):
    return sum(a * b for a, b in zip(left, right))

scale = sqrt(len(query))
scores = [dot(query, key) / scale for key in keys]
normalizer = sum(exp(score) for score in scores)
weights = [exp(score) / normalizer for score in scores]

print("scaled scores:", [round(value, 4) for value in scores])
print("weights:", [round(value, 4) for value in weights])
assert abs(sum(weights) - 1.0) < 1e-12
```

```python exec lab="scaled-dot-product-attention" cell="3" title="Aggregate value vectors" difficulty="basic"
output = [
    sum(weight * value[column] for weight, value in zip(weights, values))
    for column in range(len(values[0]))
]

print("attention output:", [round(value, 4) for value in output])
assert len(output) == len(values[0])
```
