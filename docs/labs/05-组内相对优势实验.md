# 组内相对优势实验

## 实验目标

用同一组回答的奖励均值与标准差构造相对优势，理解“比组内平均更好”与绝对奖励之间的区别。

```python exec lab="group-relative-advantage" cell="1" title="Create grouped rewards" difficulty="basic"
from math import sqrt

rewards = [1.0, 0.7, 0.2, -0.1]
mean_reward = sum(rewards) / len(rewards)
variance = sum((reward - mean_reward) ** 2 for reward in rewards) / len(rewards)
std_reward = sqrt(variance)

print({"mean": round(mean_reward, 4), "std": round(std_reward, 4)})
assert std_reward > 0
```

```python exec lab="group-relative-advantage" cell="2" title="Normalize advantages" difficulty="basic"
advantages = [(reward - mean_reward) / std_reward for reward in rewards]

for index, (reward, advantage) in enumerate(zip(rewards, advantages), start=1):
    print({"response": index, "reward": reward, "advantage": round(advantage, 4)})

assert abs(sum(advantages)) < 1e-12
assert advantages[0] > 0 > advantages[-1]
```

```python exec lab="group-relative-advantage" cell="3" title="Test shift invariance" difficulty="basic"
shifted_rewards = [reward + 10.0 for reward in rewards]
shifted_mean = sum(shifted_rewards) / len(shifted_rewards)
shifted_variance = sum((reward - shifted_mean) ** 2 for reward in shifted_rewards) / len(shifted_rewards)
shifted_std = sqrt(shifted_variance)
shifted_advantages = [(reward - shifted_mean) / shifted_std for reward in shifted_rewards]

print([round(value, 4) for value in shifted_advantages])
assert all(abs(a - b) < 1e-12 for a, b in zip(advantages, shifted_advantages))
```
