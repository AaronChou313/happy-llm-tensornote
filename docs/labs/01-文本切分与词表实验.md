# 文本切分与词表实验

## 实验目标

用一个极小语料验证：粗粒度 Token 更短，但更容易遇到词表外项；细粒度 Token 序列更长，却更容易复用已有单元。

> [!question]
> 运行前先预测：新词“学习者”在词级词表和子词词表中分别会产生几个未知 Token？

```python exec lab="tokenization" cell="1" title="Build two vocabularies" difficulty="basic"
corpus = ["语言 模型 学习", "机器 学习", "语言 理解"]

word_vocab = {token for sentence in corpus for token in sentence.split()}
character_vocab = {char for sentence in corpus for char in sentence if char != " "}

print("word vocabulary:", sorted(word_vocab))
print("character vocabulary:", sorted(character_vocab))
print("sizes:", {"word": len(word_vocab), "character": len(character_vocab)})
```

```python exec lab="tokenization" cell="2" title="Encode an unseen phrase" difficulty="basic"
text = "语言 学习者"
word_tokens = text.split()
character_tokens = [char for char in text if char != " "]

word_ids = [token if token in word_vocab else "[UNK]" for token in word_tokens]
character_ids = [token if token in character_vocab else "[UNK]" for token in character_tokens]

print("word-level:", word_ids)
print("character-level:", character_ids)
print("unknown counts:", {
    "word": word_ids.count("[UNK]"),
    "character": character_ids.count("[UNK]"),
})
```

```python exec lab="tokenization" cell="3" title="Verify the tradeoff" difficulty="basic"
assert len(word_tokens) < len(character_tokens)
assert word_ids.count("[UNK]") >= character_ids.count("[UNK]")
print("更细的粒度增加了序列长度，但复用了更多已知单元。")
```
