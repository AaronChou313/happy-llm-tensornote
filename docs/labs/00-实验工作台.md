# 实验工作台

这些 Lab 是教程正文与完整工程代码之间的桥梁。它们不下载模型、不访问网络，只使用 Python 标准库，适合在阅读过程中随时运行。

## 使用方法

1. 先阅读对应章节，并在运行前预测输出。
2. 在 TensorNote 中审阅代码并允许当前 Workspace 执行。
3. 连接 Python 3.11 或兼容的 Jupyter Kernel。
4. 使用 **Restart & Run All**，确认实验不依赖其他笔记的隐藏状态。
5. 改动一个变量，再解释观察结果为什么变化。
