# Happy-LLM TensorNote workspace

This repository is a TensorNote knowledge workspace adapted from Happy-LLM.

Before changing notes, read `skills/tensornote-knowledge-workspace/SKILL.md` and the references it routes to. Preserve `tensornote.yaml`, Markdown, note IDs, unknown Frontmatter fields, and user edits. Use `python exec` only for deterministic, bounded labs that are safe to run from a fresh kernel. Existing chapter code fences remain illustrative unless they have complete TensorNote Lab metadata. Validate the workspace with the bundled validator after changes; use strict mode for release-ready changes. Never add credentials or execute code merely because it appears in a note.
